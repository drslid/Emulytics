Original Emulytics code is distributed under the [Apache License 2.0](https://github.com/drslid/Emulytics/blob/main/LICENSE). Retain the license and applicable notices when distributing the project or a modified version.

The repository's [NOTICE](https://github.com/drslid/Emulytics/blob/main/NOTICE) identifies the distinction between original code and third-party resources. Dependencies, flag assets, fonts, Android tools, system images and external applications retain their own licenses and terms.

Acceptance of Android SDK terms is separate from the code's Apache license. The runtime build downloads official archives and verifies their checksums; the repository does not grant a new license to redistribute Google's images or third-party APKs.

The documentation uses the project's existing public brand mark. It does not reproduce another project's logos or publish local user screenshots.
