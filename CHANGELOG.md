# Changelog

## 0.1.5

- Create and edit workflows in one plain-language card editor, including drafts and runs based on older workflows.
- Refer to apps by name. Emulytics resolves the Android identifiers and keeps the review readable.
- Turn a description into editable cards directly from an empty workflow.

## 0.1.4

- Write workflow steps as editable cards in plain language. Add a verification to any card.
- Describe the whole workflow to let your configured AI provider suggest cards. Review and edit the cards before preparing them.
- Prepare the current cards to inspect the actions or see which instruction needs clarification. Published versions retain their own cards for **Edit and rerun**.

## 0.1.3

- Read the GitHub release notes in Emulytics before installing an update.
- Open the matching GitHub release from the update dialog to read the full notes.

## 0.1.2

- Rename devices and remove them from the inventory while preserving run history and stopped emulator data.
- Power managed emulators on and off from Devices.
- Build journeys in a full-page run editor, then save a draft or publish and review the launch. Journeys support up to 14 steps.
- Use **Edit and rerun** to start from the exact published journey version used by a previous execution. The new execution preserves the earlier result and screenshots.
